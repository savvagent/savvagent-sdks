# angular-example

## 0.0.1

### Features

- Initial Angular example application demonstrating `@savvagent/angular` SDK
- Feature flag evaluation with reactive updates using `flag$()` observable
- Real-time flag updates via SSE subscription
- User management (set/clear user ID)
- Error tracking demonstration for AI-powered correlation
- Local flag overrides for development and testing
- Flag override panel component with keyboard shortcut (Ctrl+Shift+F)
- Environment-based configuration for development and production
- Standalone component architecture (Angular 14+)
